# DATA public-V/B native research frame

This private program-owned unit-test module assembles actual DATA public joint
V and whole B into a complete native FRI/frame and verifies it with DATA's own
bounded receiver. Optimized native acceptance, replay and hostile checks passed.
It uses a programmable research proof-ROM and grants no production authority.

## Owner and direct dependencies

The owning dense_data_inventory declares research_data only under cfg(test),
with visibility restricted to gold::program. The
[shared hash harness](../../research_hash/README.md) owns the ONE RO/config/closed
opaque implementation. The [actual DATA image](../public_image/README.md) and
[whole-B arithmetic](../public_deep/README.md) own DATA math.
[native FullAir](../native.rs), [owning codec](../hash_wire.rs) and
[public setup](../hash_setup.rs) retain the actual family statement, bounded
frame and public stream contracts. Pinned P3 supplies native transcripts, FRI,
DFT, MMCS and verify_batch. No new Cargo dependency or normal API is introduced.

OpaqueInputs selects only DenseFamily::Data. The module defines no separate
oracle State/Config or textual copy of FRI/Ring. All receiver programming rights
remain absent.

## Actual DATA association

The owning public_data derives actual DATA native::FullAir/Assessment and
ProverData<shared Config> from the complete DATA Expected and the existing DATA
public_stream labels0/1/2. It checks PP668/degree12, one mapped instance,
81 packed lookups, 4*243 total multiplicity,243 declared elements, DATA BUS,
native tuple/column/multiplicity/flag structure and exact owning assessment.

The native PP factory obtains the actual DataFoldProgram's668 degree<4096,
zero-interleaved2048->4096 PP polynomials. It builds genuine native salted MMCS
data on bit-reversed7H32768 with the same shared RO and DATA public stream0,
and requires exact cap equality with independently created CommonData.
It retains no original private trace, encryption key, DATA Prepared or config
getter. The temporary first public PP prover bank is dropped before rebuilding
the directly openable native bank.

The DATA-specific assembler consumes its Inputs once. Its closed opaque layout
is R10, MAIN517, Q8x10, AUX415; true public PP668 is a separate normal MMCS.
Its actual ordered claims have2622 terms with PP theta offset1124.
It validates native widths, local/next shapes, every supplied PP coefficient,
all native PP opening rows, OOD PP claims, exact S/z/theta/plan association and
the nonbase theta requirement before any opaque leaf programming.

The implementation calls the existing native BatchProverTranscript,
PcsProverTranscript and SDK prove_fri. It implements no FRI algorithm or Ring.
The native assembly pattern was adapted from the reviewed Query harness, but
its Expected, FullAir, PP factory, codec, packed81 challenges,512/410 dimensions
and mathematical public V/B all belong to DATA. There is no Query fixture,
Query Expected/AIR/PP factory or relabeled Query arithmetic consumer.

Real FRI receives actual B evaluations at bit-reversed32768 points; all12 native
fold commitments, folds, final polynomial and multiproofs are generated.
Only after ordinary FRI hashing are the four opaque INPUT leaves programmed;
shared raw-key aliases/conflicts are real failures. All192 original raw indices
are retained, repeated indices reuse exact rows/salts, and five rounds preserve
the native wrapper nesting:5 per private matrix/point,0 for PP, R outer5+wrapper5.

## Frame/receiver and future session ownership

DATA ResearchFrame is distinct and program-internal. The encoder first invokes
the actual normal DATA hash_wire shape decoder/encoder. The receiver checks
DATA magic/profile/complete Expected binding and actual normal bounded shape,
then performs a second bounded research-Config parse with canonical re-encode
and EOF. Its limits are unchanged:4096 sequence elements,4MiB total slots and
4MiB frame. It runs actual native verify_batch with independently owned DATA
Expected, FullAir and CommonData. The receiver has only shared Oracle rights.

program-internal test-only entry points are public_expected, TapePlan,
Receiver::{new,receive,receive_bytes}, ResearchFrame::as_bytes and public_frame.
public_expected returns the owning canonical PUBLIC DATA metadata fixture;
it is no witness source. public_frame accepts a presampled DATA TapePlan and
four explicit non-secret regression streams, returning only immutable frame
bytes and a complete native Walk. All producer PP, forest, V/B and proof data
are dropped before return, allowing a later mixed Query/DATA prior-state test
without retaining multiple producers. That cross-family test is not implemented
by this module.

TapePlan owns DATA's entire277-accepted-field schema, up to4096 full64-byte raw
draws with rejection retries. It preserves the native192 low15-bit indices,
duplicates and first-unique physical positions. A fresh proof requires a fresh
independent presampled tape; common oracle state is not one reused counter tape.

## Executed checks

The small unit case checks the exact DATA raw tape, a rejected firstLE64 draw,
retained duplicate native index, missing/unused/early-accepted cells and empty
tape rejection. It requests no public PP, private trace or native proof.

The explicitly ignored full owning case is:
actual_data_native_receiver_accepts_public_joint_v_b_and_rejects_changed_native_components

It requires the existing held-image120s/1792MiB observer. It constructs actual
DATA public joint V and whole B, consumes the native assembler, encodes the full
bounded frame and invokes the genuine DATA receiver. It requires exact complete
RAW/FIELD/CAP/SAMPLE producer/receiver walks,277 accepted samples,17 caps,
all5 INPUT/12 FRI rounds, immutable query-only replay and concrete normal DATA
hash backend rejection.

Twenty-one native hostile cases check five omitted input rounds and changes to
actual DATA AUX, quotient, R outer/wrapper, MAIN/AUX wrappers, last MAIN/AUX/PP
row columns, PP OOD, PP salt, FRI root/final polynomial and zero-PoW fields.
Each mutation is independently bounded-decoded and dropped before the next;
it calls native verification directly. Six header/byte cases cover magic,
profile, Expected binding, reserved bytes, trailing bytes and short frame.
The first four additionally require no produced challenger draw.

## Remaining conditions

The [mixed Query/DATA gate](../../research_hash/MIXED-SESSIONS.md) now passes
with both families' raw dictionary and PP histories retained in measured memory.
It checks complete walks and old-frame replay after a named raw conflict.
Source/Role3/Word and the wider security model still require separate work.

The model remains a seeded programmable research proof-ROM with concrete PUBLIC
preprocessing. The code does not establish ideal independence, adaptive privacy,
concrete SHA/PRG/BFV security, Source/key/current-version association, semantic
application admission, or all-five-family composition. A successful research
frame would still grant no production authority. Network SQL, fresh weighted
agreement, finalized FOR UPDATE/SKIP LOCKED and the complete<=500ms goal remain
unimplemented/unmeasured by this module.

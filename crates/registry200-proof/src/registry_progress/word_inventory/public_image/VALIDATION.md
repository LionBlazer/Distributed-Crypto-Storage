These are finite arithmetic and source-association checks of the actual original
Word Predicate AIR. The public MAIN/AUX fixtures are deliberately arbitrary
polynomials, not private witnesses. No Word proof, FRI frame, admission verdict,
current head, SQL result or finalized lock was produced by these gates.

All four exact cases passed with zero failed and zero ignored. The full192 and
native-PP cases are ignored by the ordinary suite and were explicitly selected
with --exact --ignored. Native ProgramAir/LogUp/folder code independently checks
all five quotient coordinates, including the five coefficient embeddings at a
fixed nonbase point. The all-PP check compares all 731,136 interleaved cells and
the complete 8192x714 public LDE from the sealed owning native factory. An ordinary
hash config in that test reads only the public bank; it makes no private commit.

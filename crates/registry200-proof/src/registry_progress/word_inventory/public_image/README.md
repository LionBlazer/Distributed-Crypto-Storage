# Word Predicate public image

This owning `cfg(test)` module evaluates the actual Word Predicate AIR and its
packed LogUp quotient in the finite coefficient ring. It associates all 309
independently derived public words and the actual 714 public preprocessing
polynomials. It returns five separate base-coordinate quotient residues.

`WordFoldProgram::from_metadata` rebuilds the closed `complete_role(true)` graph,
original `Plan`, golden check, native assessment and existing resource checks.
`Expected::checked` reaudits the original Source statement and derives every
public group. Predicate=false is rejected. The binding is the complete existing
`probe::binding(metadata)`; a later SHA frame consumer still owns its distinct
wire/profile binding. This image does not mint a frame, proof or admission token.

## Geometry and ownership

The original subgroup is H512, hiding degree bound is 1024 and physical input
domain is 7H8192. MAIN has 568 base polynomials. Native default packing combines
98 original messages into 34 contexts; AUX has 35 extension polynomials, retained
as 175 separate base-coordinate polynomials. PP has 714 columns, PUBLIC has 309
values, and no periodic columns are supported. MAIN/PP next-row declarations
remain the actual full native declarations.

The packed global buses are the actual `ssa`, `mask256` and `policy25` buses. The
SDK assigns IDs in first-seen packed-context order. The largest message width is
five. This module derives the bus table from those contexts with native
`Challenges::new(alpha,beta,5,3)`. A test obtains the reference 68 lookup challenges
from the genuine batch transcript and checks exact agreement, including a
negative control for the obsolete width-two/one-bus formula.

For at most 192 public physical locations S, `DisclosureDomain::checked(z,S)`
constructs M for S union {z} and M_T for S union hS union {z,hz}, using all five
Frobenius conjugates for each nonbase point. Target degree is at most 197 and
source degree at most 394, within the shared Ring's unchanged monic length395
bound. The exact maps M|M_T and M|M_T(hX) are checked. Rotation is a map into the
target quotient; the module does not assume that rotation acts on the enlarged
source quotient. Duplicate and overlapping locations are handled as sets. Points
of the original H512 and nonphysical members of S are rejected. Exceptional PCS
conditioning, including how z is sampled, remains a later transcript owner's job.

`PublicResidues::checked` consumes the MAIN568 and AUX175 public residue vectors
and retains their exact source modulus. `WordFoldProgram::fold` rejects a foreign
modulus. It evaluates all actual native constraints in their global interleaved
Horner order, not by concatenating the separated base and extension lists. Each
extension coefficient lives in the original u^5=3 basis; only polynomial X is
projected. Selectors and division use the original X^512-1. The output retains all
five coordinate polynomials modulo M and the actual emitted constraint count.

The immutable symbolic DAG is memoized by live expression identity, bounded by
262144 cached nodes and 16384 emitted constraints. The existing assessment/resource
checks still apply. These finite limits are not a measurement of full-process RAM.

## Owning checks

The two ordinary unit cases compare with the actual SDK verifier constraint
folder, derive the complete Expected309, exercise changed PUBLIC/PP
controls and malformed shapes, and cover nonbase conjugates and overlapping hS.
The PP-next negative control records that the actual AIR reads current PP; the
native opening protocol nevertheless requests both complete PP rows.

Two expensive checks are explicitly ignored and must run individually under the
owning held-process observer with a 120-second / 1792-MiB limit:

- `all_five_word_coordinate_polynomials_match_native_folder_on_192_rows_and_five_ood_embeddings`:
  compares all five coordinates at 192 distinct physical points and all five
  coefficient-Frobenius embeddings at nonbase z, plus a lossy one-map negative
  control. The reference uses actual native ProgramAir/LogUp/folder evaluation.
- `actual_word_pp_coefficients_match_zero_interleaving_and_the_native_public_lde_current_and_next`:
  reconstructs every cell of the genuine 512-to-1024 zero interleaving, rejects
  naive H512 interpolation, and compares the complete 8192x714 LDE against the
  sealed owning native public setup. Sparse scalar checks fix current/next
  rotation and native order.

Public MAIN/AUX polynomials in these checks are arbitrary explicit arithmetic
fixtures, not a valid private witness. Public transcript caps in the folder oracle
are explicit constants, not a produced proof. The validation record distinguishes
source review, arithmetic gates and actual proof execution.

The four owning cases passed in the [bounded validation](VALIDATION.md). That
record separates arithmetic execution from proof or full-query performance.

## Later consumers

programmable RO, a native Word frame/FRI, independent receiving admission, SQL,
current-head agreement or locks. The later Word DEEP consumer must retain exactly
two PP714 openings. Its native claim inventory is
`R10 + MAIN573x2 + Q80 + PP714x2 + AUX180x2 = 3024` extension claims;
PP begins at theta offset 1236. No DATA or
Query offset, dictionary, twelve-fold FRI schedule or frame may be relabeled as
Word. Native Word requires its own ten-fold schedule and ownership/resource gate.

Nothing here establishes the 500-ms full-query target, adaptive privacy, production
soundness or a receiving capability. Unmet system requirements remain unchanged.

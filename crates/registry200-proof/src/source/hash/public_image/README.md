# SourceVersion public quotient image

This private cfg(test) child of [source::hash](../mod.rs) interprets the actual
[OpeningAir](../../air.rs) over finite polynomial quotient rings. It captures the
full sealed [SourceVersionExpected](../../version/README.md),691 public values,
MAIN7161, the ordinary base-constraint emission order and the genuine512-period
[schedule](../../schedule.rs). It creates arithmetic data, not a witness, proof,
verifier verdict or fresh-head capability.

Direct dependencies are the owning Source AIR/private prescreen, pinned P3
symbolic builder/DFT/domain/native folder APIs and the shared pure
[coefficient Ring](../../../../../proof-research-support/src/ring.rs). No Query/DATA fixture, RO, proof configuration,
caller-provided verifier or alternate Source relation is used. The SDK symbolic
builder supplies the actual generic AirBuilder contract over Gold/EF5; Ring
receives no fake Field implementation.

`SourceFoldProgram::from_expected` keeps all real base expressions, rejects an
extension stream or changed global ordering and counts the exact live DAG nodes.
`fold` projects all7161 public MAIN residues from the enlarged domain into the
current/next target domains, evaluates ordinary AIR/periodic leaves and native
Horner alpha order, then returns five separate BASE quotient-coordinate
polynomials. Results retain the full691 public tuple and modulus;
`require_expected` checks public association only. It cannot grant proof or
application authority. C_state is retained even though version_id excludes it.

Periodic columns are plain inverse-DFT interpolation of the actual512x512
one-hot schedule on ORIGINAL H512. They are not PP and are never zero-interleaved
to1024 or committed as another matrix. Native IsFirstRow/IsLastRow are the
unnormalized Z_H/(X-1), Z_H/(X-h^-1); periodic L_r has normalization h^r/512.
MAINnext uses h of order512, and the quotient denominator is X^512-1.
The input-row domain is7*H8192; enlarged/target degrees remain<=394/197 under
at most192 physical locations, within the unchanged pure Ring limit.

Four small owning cases cover actual periodic coefficients and independent SDK values,
the deliberately wrong1024-padded periodic sum, all five scalar quotient
coordinates of the complete AIR, full-public/domain/cache refusal controls, and
a nonbase case with three physical locations plus all five coefficient embeddings.
A corrupted tensor passes those base locations and the first collapsed embedding
but fails the remaining embeddings. In every native comparison Config is a TYPE
argument only; the real OpeningAir is evaluated through VerifierConstraintFolder
without constructing any proof configuration. The nonbase point and MAIN/periodic
values stay fixed while the coefficient embedding conjugates alpha.

The PUBLIC Expected setup reuses the owning fixture. Its Owner::seal encrypts
explicitly public constants with a public fixture key and draws OS-random page
nonces. Setup is not proof/query execution and is not RNG-free. No Source witness,
private trace, FHE or proof is requested. The changed-C_state test rebuilds its
expectation from the SAME original public images/heads rather than sealing again.

The cache limit is the actual source-derived unique node count, not a DATA
constraint/cache constant. Diagnostics report real constraint/node/cache counts.
Expression roots retain all Arc children throughout pointer-identity caching.
That finite bound is not a whole-process RAM guarantee: validate the owning gate
with the existing held-process observer and unchanged resource fuse before
expanding the profile. No cases were executed while preparing this candidate.

The small owning arithmetic gate is:

```sh

```

The four small cases passed in the [owning validation](VALIDATION.md), which
records exact graph counts and process measurements without a proof or SQL claim.

adaptive privacy, freshness, SQL admission and the <=500ms complete-query target

## Actual public arithmetic

`Role3FoldProgram::from_statement` calls its parent's existing private `air`,
retaining Role3/StateCertificate re-audit, actual assessment and16 quotient-chunk
checks. It also requires MAIN1656/PUBLIC740/PP0/periodic512, all1656 next columns,
empty PP-next and public-boundary declarations, and the fixed u^5=3 basis.

The actual generic AIR is evaluated by SymbolicAirBuilder. Only an entirely
base stream in native order is accepted; an extension stream cannot silently be
ignored. No hand-written encoding equations, lookup packing, BFV role inventory,
DATA/Query AIR or Source private image adapter supplies the fold.

All512 declared periodic columns are checked against their literal one-hot512
rows and plain-IDFT interpolated on original H512. They are AIR logic, with no
PP zero interleaving. The normalized periodic polynomial for row r has coefficient
h^(-r*t)/512 at X^t. Native boundary selectors remain unnormalized:
first=Z_H/(X-1), last=Z_H/(X-h^-1), transition=X-h^-1, with Z_H=X^512-1.
The hiding degree1024 changes none of these AIR polynomials or the hX next point.

`DisclosureDomain::checked` constructs target M for S union{z} and source M_T
for S union hS union{z,hz}, retaining all five conjugates at nonbase points.
For at most192 physical positions in7H8192, degree limits are197/394 under the
unchanged shared Ring monic-length395 guard. It checks the two exact maps into
the target and the original vanishing unit. Duplicate/overlapping positions are
sets; rotation is not assumed to act within the enlarged source quotient.
Exceptional PCS sampling conditions remain a later protocol owner's job.

`PublicResidues::checked` consumes exactly1656 base-polynomial residues with the
source-degree limit and retains M_T. `fold` rejects another source modulus,
projects MAIN to X/hX, and evaluates the actual DAG with five separate coefficient
coordinates. Native global Horner folding and division by Z_H produce the output.

The program counts unique live expression addresses in THIS actual Role3 DAG.
Its immutable roots retain all Arc children, and that exact count bounds the
fold cache. Every small fold checks cached_nodes==node_count and logs actual
constraint/node counts when executed. No DATA/Source numeric cache cap is copied,
and diagnostics report actual counts when this owning gate executes. This cardinality
bound is not a whole-process RAM/time bound.

`QuotientResidues::require_statement` checks both all740 values and the original
full SHA binding. It binds profile8 + Source691 + key metadata29 + encoding
context8 + Cw4, plus complete length-framed Source heads and packets. The encoding
context intentionally excludes its own Cw and cannot replace this association.
These checks associate arithmetic; they authenticate neither a key nor Source.

  interpolation/sum1, correct boundary normalization, and a deliberately wrong

  five fixed-z coefficient-Frobenius embeddings, an actual corrupted tensor

independent native reference calls actual EncodingAir.eval with genuine SDK
periodic values/selectors and VerifierConstraintFolder. It does not call the Ring
evaluator. At nonbase z, z and all rows stay fixed while only coefficient alpha
is Frobenius-transformed; all five coefficient embeddings are retained.
